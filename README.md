## Projeto Integrador — Sistema Acadêmico

Aplicação web full-stack que consulta um banco acadêmico (PostgreSQL via Supabase) e exibe, com busca por nome ou turma: nome do aluno, e-mail, turma, data de matrícula, notas e média final.

**Stack:** React + Vite · Node.js + Express · PostgreSQL · Supabase

**Papel:** Líder da squad — coordenei a equipe e auxiliei em todas as frentes (banco de dados, backend e frontend).

## Conceitos praticados

- Modelagem de dados e DER
- DDL e DML — criação de tabelas, inserção e consultas
- Views SQL (`vw_alunos`)
- JOINs, filtros e agrupamentos
- API REST com Node.js + Express
- Integração frontend-backend
- PostgreSQL hospedado no Supabase
